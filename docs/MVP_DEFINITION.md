# COALICIÓN — MVP vendible

## Incluido

- Sala de situación Web para móvil, tablet y escritorio.
- Registro de encuestas actuales materializado y trazable.
- API JSON para estado, encuestas, evidencia y demo.
- Pipeline electoral territorial fail-closed.
- Newsletter diaria generable y envío SMTP opcional.
- Evidencia y límites visibles para el usuario final.
- Despliegue Render gratuito preparado mediante `render.yaml`.

## No incluido en el MVP

- Inferir encuestas territoriales desde una media nacional.
- Presentar una predicción 2026 como certificada sin calibración 2026.
- Auditoría externa como si estuviera realizada.
- API comercial avanzada, BMA/GP/QRF/DLM, exportación Office o lenguaje natural avanzado.

## Regla de producto

El MVP puede venderse como **beta/demo no oficial**. Una superficie queda como NO DISPONIBLE cuando la evidencia necesaria no existe.
