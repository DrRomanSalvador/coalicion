# COALICIÓN — SALES PITCH

## Qué se compra

Una infraestructura operativa para seguir encuestas, comprobar evidencia, explorar escenarios electorales y traducir composiciones territoriales explícitas a resultados parlamentarios reproducibles.

## Valor

- Sala de situación operativa.
- Vigilancia de fuentes y cambios.
- Evidencia fechada y trazable.
- Simulación territorial y D'Hondt determinista.
- Escenarios de coalición como contrafactuales matemáticos.
- Telegram para consultas y alertas.
- API y panel web para integración.

## Diferencia

COALICIÓN no presenta una inferencia nacional→escaños como hecho. Cuando falta territorialidad explícita, bloquea. Cuando existe una simulación, conserva su procedencia y parámetros.

## Estado comercial

SELLABLE_BETA: producto operativo para demostración y uso profesional bajo las condiciones documentadas.

La capa de predicción no se presenta como certificada. La auditoría externa permanece abierta.

## Entrega

1. Acceso al panel/API.
2. Configuración de fuentes y alertas.
3. Canal Telegram autorizado.
4. Exportación de evidencia.
5. Soporte de puesta en marcha.
