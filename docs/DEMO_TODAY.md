## Superficie

- Web/API: estado, encuestas y predicción demo.
- Telegram: `/demo`, `/encuestas`, `/territorio`, `/escanos`, `/evidencia`, `/exportar`.
- Predicción: 52 circunscripciones / 350 escaños.
- Evidencia actual: 10 encuestas nacionales de entrada.
- Modelo territorial: media nacional actual + patrón espacial 2023.
- Estado: demostración no oficial.

## Regla de publicación

La predicción demo está marcada explícitamente como modelada y no oficial. No se presenta como encuesta territorial observada ni como certificación probabilística 2026.

La auditoría externa independiente y la certificación oficial siguen siendo requisitos posteriores para validez oficial.
