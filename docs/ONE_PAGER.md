# COALICIÓN — ONE-PAGER

Producto: plataforma de inteligencia electoral reproducible.

Para: equipos que necesitan saber qué ha cambiado, qué evidencia lo sostiene y qué escenarios son matemáticamente posibles.

## En una pantalla

Sondeos → evidencia → territorio → D'Hondt → escenarios → decisión

## Incluye

- Monitor de encuestas.
- Sala de situación.
- Calendario electoral.
- Territorio con evidencia explícita.
- Simulación de escenarios.
- Comparación de coaliciones.
- Telegram.
- API.
- Exportación de evidencia.
- Docker + CI reproducible.

## Estado

SELLABLE_BETA / READY_FOR_EXTERNAL_AUDIT

Uso comercial como beta operativa. No significa auditoría externa ni certificación predictiva.

## Primer uso

Configurar las credenciales del API/Telegram y ejecutar la imagen Docker o desplegar el blueprint de Render incluido.
