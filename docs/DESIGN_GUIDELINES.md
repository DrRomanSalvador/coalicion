# COALICIÓN — Diseño del MVP

## Principios

1. **Una pantalla, una respuesta.** El usuario debe identificar el dato principal sin leer documentación técnica.
2. **Estado visible.** PASS, DEMO, BLOCKED y NO DISPONIBLE nunca se ocultan.
3. **Evidencia junto al dato.** Fecha, fuente y nivel de evidencia aparecen cerca de la observación.
4. **Neutralidad.** No se prioriza ningún partido mediante copy, color, orden editorial o recomendaciones.
5. **Móvil primero.** Tablas compactas y métricas legibles en teléfono.
6. **No falsa precisión.** Los intervalos y limitaciones se muestran cuando existen; si no, no se inventan.
7. **Territorio explícito.** Nunca se presenta una inferencia nacional como encuesta territorial.

## Navegación MVP

- Situación
- Encuestas
- Territorio
- Escaños
- Evidencia

La interfaz comercial no sustituye la cadena de evidencia ni la auditoría.
