# Extensiones metodológicas de COALICIÓN

Estado: integradas como extensiones reproducibles. No sustituyen el núcleo electoral, OOS ni SEEC.

No se declaran MAE, coverage, sensibilidad o velocidad como resultados observados hasta ejecutar un backtest OOS reproducible.

Componentes: Ensemble, BMA, bootstrap de bloques, conformal, Gaussian Process, Quantile Regression Forest, optimización robusta, Sobol, LSTM opcional, DID/RDD opcional y diagnósticos espaciales opcionales.

Reglas: no convertir escaños en votos; no leakage temporal; fuentes oficiales y SEEC como evidencia primaria; D'Hondt exclusivamente en electoral.py; promover a producción solo tras validación OOS; no presentar intervalos como calibrados sin evidencia.
