# OUTREACH — COALICIÓN

## Asunto

COALICIÓN: sala de situación electoral reproducible

## Mensaje

Hola,

te presento COALICIÓN, una plataforma de inteligencia electoral diseñada para equipos que necesitan trabajar con encuestas, territorio, escenarios y evidencia sin convertir una inferencia en un hecho.

El sistema monitoriza fuentes, conserva evidencia fechada, compara cambios y permite ejecutar escenarios territoriales explícitos con D'Hondt. También ofrece Telegram, API, panel web y exportación de evidencia.

La versión actual es una beta operativa preparada para uso profesional. Los límites de predicción y la auditoría externa se mantienen explícitos.

Si te interesa, puedo enseñarte una demostración funcional de 15 minutos con un caso neutral y reproducible.

Un saludo,
COALICIÓN
