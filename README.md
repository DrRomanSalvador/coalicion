# COALICIÓN

## Regla metodológica

**Una misma metodología, aplicada íntegramente a datos distintos, debe producir resultados reproducibles, replicables y reutilizables.**

El modelo separa estrictamente **datos observados**, **supuestos**, **transformaciones** y **resultados**. Ningún resultado puede depender de ajustes manuales realizados para aproximarse a una encuesta, un analista o un resultado esperado.

### Principios obligatorios

1. **Reproducibilidad.** Mismos datos, parámetros, reglas y versión = mismo resultado.
2. **Replicabilidad.** Un tercero puede reconstruir el resultado.
3. **Reutilización.** Cambiar datos no cambia la metodología.
4. **Trazabilidad.** Toda cifra derivada remite a datos y regla explícitos.
5. **Separación dato/modelo.** Una publicación no se presenta como resultado propio; una imputación no es un dato observado.
6. **Misma regla para todas las fuentes.**
7. **Territorialidad primero.** El voto nacional se transforma territorialmente antes de calcular escaños.
8. **Coaliciones por votos.** Se suman votos territorialmente antes de aplicar la ley electoral.
9. **Marginalidad medible.** La proximidad a un escaño se calcula mediante los cocientes reales, sin bonificaciones arbitrarias.
10. **Ley electoral literal.** Umbrales, desempates y circunscripciones especiales se reproducen exactamente.
11. **Matemática exacta cuando importe.** No se permite redondeo que pueda alterar una frontera electoral.
12. **Validación antes de proyección.**
13. **Backtesting.** Ninguna corrección de sesgo entra sin mejora demostrada fuera de muestra.
14. **Incertidumbre explícita.** Lo no identificable no se inventa.
15. **Auditoría adversarial.** Todo resultado se contrasta contra alternativas y errores históricos.

## Cadena única

**Fuente → dato → validación → corrección justificada → territorio → escenario → coalición → ley electoral → marginalidad → resultado → auditoría.**

Solo cambian los datos de entrada y los escenarios definidos. La cadena metodológica no cambia.

## Regla de oro

> **No se ajusta el resultado para que parezca correcto. La metodología solo cambia cuando la evidencia y el contraste fuera de muestra demuestran que debe cambiar.**

## Criterio de calidad

El objetivo es mejorar matemáticamente la transformación de voto en representación respecto de métodos comparados, demostrando cada mejora de forma reproducible y sin información retrospectiva.

**Si una mejora no puede demostrarse, no se incorpora.**
